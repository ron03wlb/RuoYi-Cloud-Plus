## 已知问题

### 问题 1: ruoyi-common-json 模块（83% 通过率）

**失败数**: 17 个测试
**根本原因**: Jackson ObjectMapper 静态方法 Mock 复杂度

**失败示例**:

```
- JSON 序列化空值处理
- JSON 反序列化类型推断
- 自定义序列化器的 Mock
```

**推荐解决方案**:

- 选项 A: 接受现状，将剩余部分移至集成测试（推荐）
- 选项 B: 重构为依赖注入模式（工作量大，约 108 人时）

### 问题 2: ruoyi-common-excel 模块（67.5% 通过率）

**失败数**: 39 个测试
**根本原因**: Excel 模板文件 I/O 和 EasyExcel 集成

**失败示例**:

```
- Excel 模板验证
- 多 Sheet 导入/导出
- 动态表头生成
- 数据格式转换
```

**推荐解决方案**:

- 使用真实 Excel 文件的集成测试（推荐）
- 或简化为仅测试非 Excel 逻辑

### 问题 3: MapstructUtils 依赖

**影响范围**: 约 60 个 Service 方法（insertByBo, updateByBo）
**原因**: MapstructUtils 需要 Spring 容器初始化

**解决方案**: 使用 @SpringBootTest 集成测试进行验证
