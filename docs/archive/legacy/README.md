## ℹ️ 为什么归档？

2025年11月进行了文档重组（v4.0），将文档结构优化为：

- **active/**: 活跃文档区（频繁更新）
- **reference/**: 参考文档区（稳定资料）
- **archive/**: 归档区（历史记录）

旧版文档存在的问题：
- ❌ 信息重复，多个文档描述相同内容
- ❌ 更新不同步，导致信息不一致
- ❌ 文件混在根目录，难以管理

新版文档的改进：
- ✅ 清晰的分类和层次结构
- ✅ 消除重复，单一信息源
- ✅ 便于维护和更新
